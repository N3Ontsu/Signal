# Signal

> A lightweight communication and moderation plugin for Paper servers.

Signal is a communication-focused Minecraft plugin designed to provide a clean and flexible chat experience, alongside private messaging and Discord integration.

## ✨ Features

- 💬 Custom chat formatting
- 📩 Private messaging
- ↩️ Reply system
- 💻 Discord integration
- 🛠️ Communication and moderation utilities
- ⚙️ Configurable messages and settings

## 📦 Installation

1. Download the latest version of **Signal** from the [Releases](../../releases) page.
2. Place the `.jar` file into your server's `plugins` folder.
3. Start or restart your server.
4. Configure Signal in:

```text
plugins/Signal/config.yml
